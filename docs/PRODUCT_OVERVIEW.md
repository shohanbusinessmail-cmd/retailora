# Product overview

Dokanora is a provisional identity for a planned Bangladeshi Bengali, offline Windows retail management product. The target includes POS, purchasing, stock ledger, receivables/payables, accounting, reporting, backups and offline license activation. The current repository is a development starting point, not a working product. Scope, statuses and acceptance blockers are recorded in `PROJECT_STATUS.md`, `TASK_TRACKER.md` and `RELEASE_READINESS.md`.
