# Inventory costing — proposed

Perpetual moving weighted average per product. Store total carrying value in integer paisa and quantity as exact base ticks; derive average from the two using decimal/rational arithmetic. Purchases add allocated landed value and quantity. Sales remove value at the current average and snapshot the exact cost on each sale line. Deterministic rounding and residual rules must ensure the final withdrawal of all stock takes the entire remaining inventory value, never leaves value at zero stock or creates negative value. Cost calculation and balance checks are performed within the same write transaction as movements and journal postings.

Returns of resalable sold goods reinstate the original sale's allocated cost, not today's cost; non-resalable returns do not automatically enter saleable stock and require a separate disposal/expense treatment. Partial returns allocate original line cost deterministically, with final return taking any residual. Purchase returns reduce stock at current moving average; difference against the original supplier credit goes to a documented variance account. Adjustments, damage, expiry and waste use current average cost with an appropriate counter-account. Explicitly specify zero-stock, free items, discount/freight and negative-stock cases and test them before any inventory workflow is enabled. No costing is implemented yet.
