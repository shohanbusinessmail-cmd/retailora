# Security

This repository is public and at an early development stage. Never commit passwords, private keys, certificates, customer/license records, backups or databases. The future customer application must verify licenses with a public key only; generator signing keys stay outside source and CI. Local-only software cannot fully defend against an administrator controlling the machine. Security design and testing are pending; do not use this build with real data. Report vulnerabilities privately to the repository owner rather than posting sensitive details in public issues.
